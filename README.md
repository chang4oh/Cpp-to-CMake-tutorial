Objective: To to learn and apply GCC, CMake, Make, Ninja

## Overview

```
CMakeLists.txt  →  CMake  →  Makefile / build.ninja
                               ↓
                          Make or Ninja
                               ↓
                         Compiler (gcc/clang)
                               ↓
                            Executable
```

Make/Ninja is a tool that automates calling gcc compiler and link-executable  
CMake is build system generator (generates build file)  
Make/Ninja is build system (reads build file to compile and link executable)
I am using GCC 13.3.0 uses the C++17 standard, CMake 3.27.8, VSCode

## Terms

**G++** - is part of GNU Compiler Collection (GCC) are set of open source compilers  
this is what is used to compile and link executable

```
gcc hello.c -o hello
```

**CMake** - Reads CMakeLists.txt

- Generates a build system for a specific generator:
- Makefile (for Make)
- build.ninja (for Ninja)
- Project files for IDEs (Visual Studio, Xcode, etc.)
- CMake does not compile anything itself.
- It is a meta build system (build system generator).

**Make** - Reads Makefile

- Executes compilation and linking commands
- Designed for human-written build rules
- Slower dependency scanning and execution model compared to Ninja

**Ninja** - Reads build.ninja

- Executes compilation and linking commands
- Designed to be generated by higher-level systems (CMake, GN, Meson)
- Not intended to be written manually for large projects
- Optimized for speed and minimal overhead
